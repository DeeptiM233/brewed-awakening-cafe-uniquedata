# brewed-awakening-cafe-uniquedata
task 7
As part of my data analytics internship with Elevate Labs, I built a basic sales summary project using SQL within Python. The goal was to extract key sales metrics—total quantity sold and total revenue—from a small SQLite database and visualize the results using a simple bar chart. I connected Python to the SQLite database (sales_data.db), executed SQL queries to aggregate sales data, and imported the results into Pandas for processing. Using SQL functions like SUM() and GROUP BY, I calculated sales per product and structured the output for analysis. Finally, I leveraged Matplotlib to generate a bar chart showcasing revenue by product. This project helped me sharpen my SQL querying skills, reinforced my understanding of integrating databases with Python, and gave me hands-on experience in data visualization.
